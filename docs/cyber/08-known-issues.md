# 08 · 已知限制与未验清单

> 本文只记两件事：**已判死**（含判死的证据，用来省读者的时间）与**未验**（明确说没测）。
> 证据等级：`A` 本机自实测 ｜ `B` 同机对照实现 ｜ `C` 外部实测 ｜ `D` 推导或出处自报。
> **读法**：`判死` = 有证据表明这条路不通，**不要再试**；`未验` = 没测过。

## §3 一条必须说清的口径

**`未验` 不等于 `判死`，`判死` 也不等于 `未验`。**

- 说"未验"时**不许**附带任何倾向性判断（"大概不行"也不行）。
- 说"判死"时**必须**附判死的证据（哪条读数、什么口径、怎么变红）。
- **"改了参数但读数一模一样"先怀疑"开关没生效"，不是"这个参数不重要"**
  （`STRATA_KQ256` 就是典型：日志里**没有任何自证行** ⇒ 既不能证明它生效，也不能证明它无效）。
